# crear-agente

Crea un agente nuevo (subagente de Claude Code) a partir de `plantilla-agente.md`,
lo guarda en `.claude/agents/`, crea su `README.md` de memoria y lo sube a GitHub.

**Agentes que la usan:** ninguno; la usa Claude directamente al crear agentes.
Instrucciones completas en `SKILL.md`.
