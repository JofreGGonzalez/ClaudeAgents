# qlik-dashboards-preferencias

Preferencias estables del usuario al diseñar dashboards de Qlik Sense: KPIs
arriba, filtros siempre en un panel lateral izquierdo (nunca arriba), paleta
corporativa oficial del cliente e idioma de la interfaz.

**Agentes que la usan:** `QlikSenseAgent`. Instrucciones completas en `SKILL.md`.
