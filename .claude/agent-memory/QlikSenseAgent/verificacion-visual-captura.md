---
name: verificacion-visual-captura
description: Verificar el prototipo con una captura renderizada antes de entregarlo
type: feedback
---
Antes de entregar un prototipo HTML, renderizarlo (navegador headless) y revisar
la captura: solapes, textos cortados, contraste y alineación, en estado colapsado
y desplegado de los paneles.

**Por qué:** los errores de layout (desbordes, escalado) no se ven leyendo el
código. Si no hay navegador disponible, decirlo explícitamente en la entrega en
lugar de afirmar que está verificado.
