---
name: comparativa-estados-alternativos
description: Cómo diseñar comparativas (periodo/edición actual vs otra) con selecciones independientes en Qlik Sense
type: feedback
---
Una comparativa no puede reutilizar los mismos filtros que la vista actual: al
seleccionar, ambos lados cambiarían a la vez.

**Cómo aplicarlo:** especificar estados alternativos (uno por lado comparado) o
Set Analysis sobre campos de comparación independientes (p. ej. copias del campo
de periodo). Indicar qué objetos pertenecen a cada estado y mostrar en el diseño
dos selectores claramente diferenciados.

**Por qué:** es el fallo más típico al pasar de mockup a implementación; el
prototipo HTML oculta esta limitación.
